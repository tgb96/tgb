# TGB

App web/PWA personal para registrar rutinas físicas, tenis, cardio, sensaciones, dolores, duración, calorías e informes de progreso.

## Archivos
- index.html
- manifest.json
- service-worker.js
- icon.svg
- icon-192.png
- icon-512.png

## Subida a GitHub Pages
1. Sube todos los archivos a la raíz del repositorio.
2. Activa GitHub Pages desde Settings > Pages.
3. Abre la URL en Chrome Android.
4. Menú ⋮ > Agregar a pantalla principal.

## Nota
Los datos quedan guardados localmente en el navegador mediante localStorage.
